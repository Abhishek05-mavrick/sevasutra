# Consent Matrix — Sahayak (PS 26)

| Purpose ID | Purpose Description | Data Collected | Legal Basis / Consent Type | Retention Period | Sharing Destination | Withdrawal & Deletion Process |
|------------|---------------------|----------------|----------------------------|------------------|---------------------|-------------------------------|
| `auth_phone_otp` | Verify Indian mobile number to create Verified Applicant account and prevent abuse | Mobile number (hashed/normalised), session metadata, OTP attempt timestamps | Necessary for requested service / explicit terms acceptance at login | Active account lifetime + 30 days post-deletion for abuse logs (hashed) | SMS OTP gateway (phone number + OTP message only; never logs OTP internally) | User can delete account (`DELETE /account`); sessions revoked immediately |
| `auth_google_oidc` | Low-friction Explorer sign-in to bookmark or browse schemes | Email, display name, OIDC subject ID | Explicit OAuth consent (OIDC) | Until user unlinks or deletes account | Google Identity Services (OIDC verification only) | User can unlink Google identity or delete account (`DELETE /account`) |
| `profile_eligibility` | Evaluate deterministic eligibility across schemes | Progressive facts (`dob`, `state`, `category`, `income`, `is_student`, `is_farmer`, etc.) with provenance | **Explicit granular consent** before saving profile; `"prefer_not_to_say"` allowed | Until user edits/deletes profile or withdraws consent | **Never shared externally** without separate `portal_data_share` consent | User can edit/delete any fact or withdraw consent (`POST /consent/withdraw`) |
| `document_vault` | Store documents securely and generate scheme checklists | Uploaded PDFs/images, file metadata, virus scan status | **Explicit consent** per upload / vault activation | Until user deletes document or account | Encrypted Object Storage (private bucket, signed URLs only) | Immediate deletion from DB + object storage (`DELETE /documents/:id`) |
| `document_ocr_extract` | Extract candidate profile fields from uploaded document as suggestions | Document text/fields during extraction | **Explicit opt-in** before running OCR; extracted values require user confirmation | Transient extraction memory; confirmed values stored in `profile_facts` | Pluggable OCR provider (must have zero-retention / no-training DPA) | User can reject extraction suggestion or delete resulting fact |
| `reminders_email` | Send reminders for deadlines, missing docs, renewals, and rule updates | Email address, notification preferences, scheme IDs (no sensitive facts in subject) | **Explicit opt-in** + per-channel preference | Until user unsubscribes or deletes account | Pluggable email provider (SMTP/SES/Gmail API) | One-click unsubscribe link + preference toggle (`PUT /reminders/preferences`) |
| `reminders_sms_whatsapp` | Send urgent deadline/status alerts via SMS or WhatsApp | Mobile number, opted-in alert types | **Separate explicit opt-in** + TRAI DLT compliance | Until user opts out or deletes account | DLT-compliant SMS / approved WhatsApp provider | Reply STOP or toggle off in preferences |
| `portal_data_share` | Submit mapped fields to an authorised government API (Phase 6) | Explicitly mapped & previewed profile fields + document references | **Per-submission explicit consent** with field-level preview | Audit log of consent artefact + external reference ID | Named authorised government API only (e.g., API Setu / DigiLocker) | Cannot un-submit to external portal once sent; user can withdraw future sharing |
| `analytics_pseudonymous` | Aggregate service reliability & discovery metrics | Pseudonymous event counts (scheme views, state counts — no PII/facts) | Legitimate product reliability / opt-out supported | 12 months aggregated | Internal observability store only; **no advertising/sale** | Toggle off analytics opt-in in privacy settings |
